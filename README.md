# Anna Sogrina

People and Organisational Development lead, based in Valencia, Spain.

I design people systems for engineering organisations going through change: performance and levels, leadership development, and the people side of moving to AI-native ways of working. Most of my career has been spent working with R&D teams and engineers.

I'm not a software engineer. I build these tools with Claude Code, because the question I work on at work is the same one I face here: what should be automated, and which decisions must stay with a person.

## Projects

- **[second-brain-agents](https://github.com/annasogrina85-rgb/second-brain-agents)**: a personal operating system of scheduled AI agents and small scripts on top of a notes vault. Agents sort the inbox, keep one task list, write the morning briefing and the weekly summary. Code, not an agent, checks every morning that they did their job.
- **[ai-job-search-people](https://github.com/annasogrina85-rgb/ai-job-search-people)**: my job search, run like a process I would redesign at work. It watches employers' own job boards, filters with hard gates before scoring fit, and drafts application packages. Applying always stays with me.

## What these projects have in common

- **One owner for every decision.** Each file has one writer and each agent has one output, so when something breaks there is one place to look.
- **Humans stay in the loop where it matters.** Agents search, sort, draft and check. Choosing, sending and speaking for me stay mine.
- **Every correction becomes a rule.** When an agent gets something wrong, the reason goes into its instructions with a short precedent, so the mistake doesn't come back.
